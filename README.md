# Выбираем вместе

Вставляете ссылки с Ozon, Wildberries, Яндекс Маркета и AliExpress — получаете карточки с фото, ценой, оценкой и отзывами. Двое (парень и девушка) отмечают понравившееся сердечком, вкладка «Обоим» показывает совпадения.

- `docs/` — сайт для GitHub Pages (чистый HTML/CSS/JS, без сборки).
- `worker/` — Cloudflare Worker: парсер ссылок и база карточек/лайков (D1).

## Запуск за пару кликов

1. Сервер: нажмите кнопку и следуйте шагам Cloudflare (бесплатно, база создастся сама).

   [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/Yaroslaz/markets-pars/tree/main/worker)

2. Скопируйте адрес вида `https://markets-pars.<аккаунт>.workers.dev` и вставьте его на сайте в «Настройки → Адрес сервера» — или пропишите в `docs/config.js`, чтобы он был у всех по умолчанию.

Сайт: https://yaroslaz.github.io/markets-pars/

### Вручную через wrangler

```bash
cd worker
npm install
npx wrangler login
npx wrangler deploy
```

## Что умеет парсер

| Магазин | Что достаём |
| --- | --- |
| Wildberries | название, все фото, оценка и число отзывов; цена — из API карточки, а если оно закрыто — из истории цен (помечается значком) |
| Яндекс Маркет | название, галерея, цена, оценка, отзывы; короткие ссылки `market.yandex.ru/cc/…` |
| Ozon | название, фото и цена из метаданных открытой страницы. Если магазин ограничивает доступ, карточка создаётся по ссылке, а данные можно дополнить вручную |
| AliExpress | данные из метаданных открытой страницы. Если магазин ограничивает доступ, можно вставить весь текст из «Поделиться» для названия и цены или дополнить карточку вручную |

Ссылки можно вставлять пачкой и вперемешку с текстом: лишние слова, эмодзи, знаки препинания и чужие ссылки отбрасываются, склеенные ссылки разделяются, дубли схлопываются.

## Импорт из открытой страницы Ozon или AliExpress

Если магазин показывает проверку, откройте товар в Safari или Chrome и пройдите её там. В «Добавить товары → Импорт из Ozon и AliExpress» можно скопировать код закладки «Вместе». Один раз сохраните его как адрес закладки в этом браузере.

На странице товара запустите закладку. На Android введите её имя в адресной строке и выберите закладку из подсказок. Нажмите «Скопировать данные», вернитесь в подборку, вставьте текст и нажмите «Добавить». Импорт обновляет доступные поля уже добавленного товара. В подборку передаются ссылка, название, цена в рублях и ссылки на фото из карточки.

Цены и рейтинги обновляются в фоне раз в 6 часов при открытии сайта, либо кнопкой «Обновить» в карточке.

## Локальная разработка

```bash
cd worker && npx wrangler dev --port 8787
```

```bash
python -m http.server 5500 --directory docs
```

Откройте `http://localhost:5500/?api=http://127.0.0.1:8787`.
