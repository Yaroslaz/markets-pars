# Выбираем вместе

Вставляете ссылки с Ozon, Wildberries, Яндекс Маркета и AliExpress — получаете карточки с фото, ценой, оценкой и отзывами. Двое (парень и девушка) отмечают понравившееся сердечком, вкладка «Обоим» показывает совпадения.

- `docs/` — сайт для GitHub Pages (чистый HTML/CSS/JS, без сборки).
- `worker/` — Cloudflare Worker: парсер ссылок и база карточек/лайков (D1).

## Запуск за пару кликов

1. Сервер: нажмите кнопку и следуйте шагам Cloudflare (бесплатно, база создастся сама).

   [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/Yaroslaz/markets-pars/tree/main/worker)

2. Настройте пароль сервера через [секрет APP_ACCESS](worker/README.md#вход-в-приложение).

3. Скопируйте адрес вида `https://markets-pars.<аккаунт>.workers.dev` и вставьте его на сайте в «Настройки → Адрес сервера» — или пропишите в `docs/config.js`, чтобы он был у всех по умолчанию.

Сайт: https://yaroslaz.github.io/markets-pars/

### Вручную через wrangler

```bash
cd worker
npm install
npx wrangler login
npx wrangler deploy
```

## Что умеет парсер

| Магазин | Что достаём |
| --- | --- |
| Wildberries | название, все фото, оценка и число отзывов; цена — из API карточки, а если оно закрыто — из истории цен (помечается значком) |
| Яндекс Маркет | название, галерея, цена, оценка, отзывы; короткие ссылки `market.yandex.ru/cc/…` |
| Ozon | название, фото и цена из метаданных открытой страницы. Если магазин ограничивает доступ, карточка создаётся по ссылке; в [приложении для Android](#приложение-для-android) данные читаются с телефона |
| AliExpress | данные из метаданных открытой страницы. Если магазин ограничивает доступ, можно вставить весь текст из «Поделиться» или открыть ссылку в [приложении для Android](#приложение-для-android) |

Ссылки можно вставлять пачкой и вперемешку с текстом: лишние слова, эмодзи, знаки препинания и чужие ссылки отбрасываются, склеенные ссылки разделяются, дубли схлопываются.

Добавить товар можно с любого устройства, в том числе с iPhone. Если сервер не может раскрыть короткую ссылку (`ozon.ru/t/…`, `market.yandex.ru/cc/…`, `aliclick.shop/…`), карточка всё равно создаётся как заготовка «Товар Ozon» (для AliExpress название и цена берутся из текста «Поделиться»). Позже кнопка «Обновить N» в [приложении для Android](#приложение-для-android) или с [расширением браузера](#расширение-для-браузера) раскроет ссылку и перенесёт карточку на настоящий товар вместе с лайками.

## Фото и проверка магазина

Вставьте ссылку на товар и нажмите «Добавить». Worker читает фото из галереи и метаданных открытой карточки. Для уже сохранённого товара в меню карточки есть «Обновить цену и фото».

Если магазин показывает проверку, нажмите «Открыть проверку». Страница откроется внутри приложения, если магазин разрешает встраивание. Если телефон открывает приложение магазина, скопируйте ссылку из этого окна и вставьте её в адресную строку браузера. Если магазин ограничивает доступ для сервера, можно сохранить изображение на телефоне и выбрать «Добавить фото» прямо в карточке. Загруженное фото видно в общей подборке после входа по паролю.

Цены и рейтинги обновляются в фоне раз в 6 часов при открытии сайта, либо кнопкой «Обновить» в карточке.

## Приложение для Android

Серверы Cloudflare магазины часто не пускают: Ozon отвечает «Похоже, нет соединения», Маркет и AliExpress показывают капчу. Поэтому в `android/` лежит небольшое приложение, которое читает страницы товаров с самого телефона, так же, как это делают браузерные расширения-парсеры:

- приложение показывает этот сайт и передаёт ему объект `MarketsNative`;
- когда вы добавляете ссылку на Ozon, Маркет или AliExpress (или делитесь ею из приложения магазина через «Поделиться → Выбираем вместе»), сайт просит приложение прочитать товар;
- приложение открывает страницу в скрытом браузере **под** сайтом, с IP и cookies телефона, и выполняет на ней `readOpenProduct` из `docs/product-import.js`. Название, цена и до 10 фото уходят на воркер через `/api/cards/import`;
- если магазин показывает проверку («я не робот», блокировка сети) дольше 2,5 с или страница не читается 15 с, скрытый браузер выходит наверх с плашкой «Пройдите проверку». После проверки товар добавляется сам, а «Отмена» возвращает к сайту;
- если приложение не справилось, ссылка, как и раньше, уходит на воркер;
- «Обновить цену и фото» в карточке внутри приложения тоже работает через телефон.

Логика чтения страницы живёт на сайте (`docs/product-import.js`), поэтому, если магазин изменит вёрстку, достаточно обновить сайт, пересобирать APK не нужно.

### Сборка

Нужны JDK 17 и Android SDK (ставится вместе с Android Studio). Путь к SDK укажите в `android/local.properties` (`sdk.dir=C:/Users/<вы>/AppData/Local/Android/Sdk`).

```bash
cd android
./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Скопируйте его на телефон и установите, разрешив установку из этого источника. Чтобы открыть в приложении локальный сайт, добавьте `-PsiteUrl=http://10.0.2.2:5500/` (для эмулятора; отладочная сборка пускает HTTP только к `10.0.2.2` и `localhost`).

## Расширение для браузера

Для компьютера без Android-телефона: `extension/` — расширение для Chrome, Яндекс Браузера и Edge (в Firefox 128+ должно работать, но не проверялось). Работает так же, как приложение: даёт сайту объект `MarketsNative`, а страницы товаров Ozon, Маркета и AliExpress читает в **свёрнутом окне** вашего браузера, с вашим IP и cookies. Окно разворачивается с плашкой «Пройдите проверку», только если магазин её просит или страницу не удалось прочитать за 15 с. Закрыть окно — значит отменить.

- На сайте ссылки Ozon, Маркета и AliExpress, «Обновить цену и фото» и «Обновить N» идут через расширение.
- Кнопка расширения на открытой странице товара сразу читает его и открывает сайт с этой ссылкой. На любой другой странице она просто открывает сайт.

### Установка

1. Скачайте папку `extension` (или весь репозиторий архивом) и распакуйте.
2. Откройте `chrome://extensions` (в Яндекс Браузере `browser://extensions`, в Edge `edge://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
4. Откройте сайт и обновите страницу.

Расширение работает на `https://yaroslaz.github.io/markets-pars/` и на `localhost`. Если сайт лежит по другому адресу, поменяйте его в `extension/manifest.json` (`content_scripts.matches`) и в `extension/background.js` (`SITE_URL`).

`extension/product-import.js` — копия `docs/product-import.js`: расширение не может выполнять код, пришедший с сайта. Если меняете «читалку», скопируйте файл и нажмите «Обновить» на странице расширений.

```bash
cd worker && npx wrangler dev --port 8787
```

```bash
python -m http.server 5500 --directory docs
```
