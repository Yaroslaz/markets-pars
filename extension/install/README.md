# Установка расширения «Выбираем вместе» (Windows)

Расширение помогает добавлять товары Ozon, Яндекс Маркета и AliExpress в подборку:
страница товара читается прямо в вашем браузере, поэтому карточка получается полной.

Подходит для **Google Chrome**, **Яндекс Браузера** и **Microsoft Edge** на Windows 10/11.

## Быстрый способ: установщик

1. Скачайте файл `Установить расширение.cmd`: щёлкните **правой** кнопкой мыши по ссылке
   [Установить расширение.cmd](https://github.com/Yaroslaz/markets-pars/raw/main/extension/install/Установить%20расширение.cmd)
   и выберите **«Сохранить ссылку как…»** (или откройте файл на GitHub и нажмите кнопку
   «Download raw file» справа над текстом). Если браузер предупредит, что файл может быть
   опасен, выберите «Сохранить» / «Всё равно скачать».
   Файл уже лежит и в скачанном архиве репозитория — в папке `extension\install`.
2. Дважды щёлкните по скачанному файлу.
   - Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите
     **«Подробнее»** → **«Выполнить в любом случае»**. Так Windows реагирует на любые
     скачанные программы без цифровой подписи.
   - Если появится вопрос «Запустить этот файл?», нажмите **«Запустить»**.
3. Установщик сам скачает свежую версию расширения с GitHub в папку
   **«Выбираем вместе — расширение»** в ваших «Загрузках» (если «Загрузки» перенесены,
   например в OneDrive или на другой диск, — туда), удалит временные файлы и откроет окно
   с подсказками поверх браузера.
   Пройдите по шагам в этом окне:
   1. Нажмите «Открыть Chrome и скопировать адрес». В браузере откройте новую вкладку (Ctrl+T),
      нажмите **Ctrl+V** и **Enter** — откроется страница расширений
      (`chrome://extensions`, в Яндекс Браузере `browser://extensions`, в Edge `edge://extensions`).
   2. Включите переключатель **«Режим разработчика»** (в Chrome и Яндекс Браузере — справа
      вверху, в Edge — на панели слева).
   3. Нажмите **«Загрузить распакованное расширение»** (в Edge — «Загрузить распакованное»).
   4. В окне установщика нажмите «Скопировать путь к папке». В окне выбора папки щёлкните
      в адресную строку вверху, нажмите **Ctrl+V**, **Enter** и кнопку **«Выбор папки»**.
   5. Готово — в списке появится карточка «Выбираем вместе». Если сайт был открыт,
      обновите его вкладку (F5). Значок расширения можно закрепить через кусочек пазла
      справа от адресной строки.

Важно:

- **Не удаляйте и не переносите папку «Выбираем вместе — расширение» в «Загрузках»** —
  браузер берёт расширение из неё. Если её удалить, расширение перестанет работать.
  Будьте внимательны, когда чистите «Загрузки».
- Сам файл установщика после установки не нужен: если он лежит в «Загрузках», в окне
  будет включённая галочка «Удалить файл установщика из «Загрузок» после закрытия окна».
- **Не выключайте «Режим разработчика»** — иначе браузер отключит расширение.
  Edge иногда предлагает «отключить расширения в режиме разработчика» — откажитесь
  (закройте подсказку).

## Как обновить

1. Снова запустите `Установить расширение.cmd` (можно скачать заново) — он заменит файлы
   в той же папке «Выбираем вместе — расширение», переподключать ничего не нужно.
2. Откройте страницу расширений и нажмите круговую стрелку **↻ «Обновить»** на карточке
   «Выбираем вместе». Обновите вкладку сайта (F5).

**Если вы ставили расширение раньше** (старая версия установщика клала его в скрытую папку
`%LOCALAPPDATA%\VybiraemVmeste`): новый установщик положит расширение в «Загрузки» и удалит
старую папку. После этого один раз переподключите расширение: на странице расширений нажмите
«Удалить» на старой карточке «Выбираем вместе» и загрузите новую папку из «Загрузок»
(шаги 2–4 выше).

## Ручная установка (если установщик не запускается)

1. Скачайте архив репозитория: <https://github.com/Yaroslaz/markets-pars/archive/refs/heads/main.zip>
   и распакуйте его (правой кнопкой → «Извлечь все»). Положите папку туда, где она будет
   лежать постоянно.
2. Откройте страницу расширений (адреса — выше), включите «Режим разработчика»,
   нажмите «Загрузить распакованное расширение» и выберите папку `extension`
   внутри распакованного архива.

## Что делает установщик (и чего не делает)

- Скачивает `main.zip` с GitHub во временную папку, берёт из него только папку `extension`
  и кладёт её в «Загрузки» → «Выбираем вместе — расширение». Папку «Загрузки» узнаёт у
  Windows (известная папка Downloads), поэтому перенесённые «Загрузки» тоже подходят. Если
  запустить установщик из скачанного репозитория и интернета нет, он возьмёт соседнюю
  папку `extension`.
- Чужую папку не перезапишет: если «Выбираем вместе — расширение» уже существует и в ней
  нет нашего `manifest.json`, установка остановится.
- После установки удаляет всё временное: скачанный архив и распакованные файлы (и такие же
  временные папки от прерванных запусков старше часа). Старую папку
  `%LOCALAPPDATA%\VybiraemVmeste` удаляет, только если в ней лежит одно наше расширение,
  и только когда новая копия уже на месте. Папку с расширением в «Загрузках» не трогает.
- Находит установленные Chrome, Яндекс Браузер и Edge (браузер по умолчанию выбирается
  сразу), копирует нужный адрес или путь в буфер обмена и показывает шаги.
- **Не** меняет реестр, политики браузеров и настройки безопасности, не требует прав
  администратора. PowerShell запускается с `-ExecutionPolicy Bypass` только для этого
  одного запуска — системная настройка не меняется.
- Удалить всё: на странице расширений нажмите «Удалить» на карточке, затем удалите папку
  «Выбираем вместе — расширение» из «Загрузок».

Ключи для проверки (передаются файлу из командной строки):
`-Browser chrome|yandex|edge`, `-NoLaunch`, `-NoGui`, `-NoPause`, `-Local`,
`-Target <папка>`, `-Downloads <папка>`, `-LegacyDir <папка>`, `-GuiSnapshot <файл.png>`.

## Почему нельзя установить «в один клик»

Без публикации в магазине расширений браузеры на Windows не позволяют установить
расширение без ручных шагов.

- **Chrome и Edge** на Windows не устанавливают `.crx` не из магазина. Принудительно
  поставить такое расширение можно только корпоративной политикой и только на компьютерах
  в домене / Azure AD / Chrome Enterprise — для домашних компьютеров это не вариант, и
  менять политики мы не будем.
- Ключ запуска `--load-extension` в Google Chrome отключён начиная с версии 137.
- Адреса `chrome://extensions`, `edge://extensions`, `browser://extensions` браузеры
  не открывают из командной строки (проверено: Chrome 157, Edge 157, Яндекс Браузер 26.10) —
  поэтому установщик копирует адрес, а вы вставляете его сами.
- **Яндекс Браузер** по справке умеет ставить упакованный `.crx` перетаскиванием на
  страницу `browser://tune`, но там же сказано, что он отключает расширения из
  непроверенных источников, — надёжнее тот же способ «Загрузить распакованное».

Настоящая установка в один клик (и автообновление) появится, только если опубликовать
расширение в **Интернет-магазине Chrome** — оттуда его могут ставить Chrome, Яндекс
Браузер и Edge.

### Что нужно для публикации в Chrome Web Store

- [ ] Аккаунт разработчика Chrome Web Store: разовый взнос **5 $**, подтверждённая почта
      разработчика.
- [ ] ZIP с содержимым папки `extension` (без папки `install`), `manifest.json` с номером
      версии; при каждом обновлении — номер версии выше.
- [ ] **Политика конфиденциальности** (страница по публичной ссылке): какие данные читает
      расширение (страницы товаров Ozon / Яндекс Маркета / AliExpress), куда передаёт
      (только на сайт «Выбираем вместе» в этом же браузере), что ничего не продаётся
      и не передаётся третьим лицам.
- [ ] Заполненная вкладка **Privacy practices**: единственное назначение расширения
      (single purpose) и обоснование каждого разрешения — `scripting` и host-разрешений
      на домены маркетплейсов (`*.ozon.ru`, `market.yandex.ru`, `*.aliexpress.ru` и др.).
      Широкие host-разрешения — частая причина долгой ручной проверки, их нужно
      объяснить простыми словами.
- [ ] Описание на русском (кратко и подробно), категория, язык.
- [ ] Иконка 128×128 (уже есть в `icons/128.png`), минимум один **скриншот 1280×800**
      или 640×400, по желанию — промо-картинка 440×280.
- [ ] Проверка Google: обычно от нескольких дней до пары недель.

После публикации установка сводится к кнопке «Установить» на странице магазина, а
обновления приходят автоматически. Edge может ставить расширения из Chrome Web Store
после разрешения «Разрешить расширения из других магазинов»; при желании расширение
можно отдельно опубликовать в Microsoft Edge Add-ons (бесплатно).
